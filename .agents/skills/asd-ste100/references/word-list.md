# Approved word substitutions (ASD-STE100)

Use this file when you are not sure about a word. The left column is a word that
STE does not approve. The right column gives the approved word or words. When more
than one alternative is given, choose the one that keeps the meaning.

A word in the left column can still be correct as a technical noun or a technical
verb in your subject field (rule 1.5 and rule 1.12). For example, `file` is not
approved as a verb, but `file` is a correct technical noun.

This list is a working aid derived from the ASD-STE100 Issue 9 dictionary. It is not
the official dictionary. The full standard is at https://www.asd-ste100.org.
